# サンプルを編集する

録音または読み込んだサンプルは、鳴らす範囲、音量、音程、再生方法をパッドごとに調整できます。

最初は`Start / End`、`Volume`、`Pitch`の3つだけ覚えれば十分です。

## Edit画面を開く

1. ビートとLoopを止めます
2. パートを`SAMPLER`にします
3. `SOUND`モードにします
4. 編集したいパッドを1回押してPreviewします
5. 同じパッドをもう一度短く押します

波形と編集項目が表示されたらEdit画面です。

## 基本操作

1. 編集したい項目のパッドを押します
2. 右側の下のダイヤルを回して値を変えます
3. `Fn1`のPreviewで結果を聴きます
4. 調整できたら`Fn2 OK`で終了します

`Fn3 EXIT`でも画面を閉じられます。確実に保存して終えるときは`Fn2 OK`を使います。

## Start / End { #start-end }

サンプルのどこからどこまでを鳴らすか決めます。

- P9 `Start`：鳴り始める位置
- P10 `End`：鳴り終わる位置

### ダイヤルで調整する

1. P9 `Start`またはP10 `End`を押します
2. 下のダイヤルを回します
3. `Fn1`でPreviewします

声の前に無音がある場合はStartを後ろへ、音のあとに余白がある場合はEndを前へ動かします。

### 音を聴きながら位置を決める

`Fn1`でPreviewしている途中にP9 `Start`またはP10 `End`を押すと、その再生位置を境界にできます。

P9またはP10を長押しすると、その境界を元の端まで戻せます。

## Volume { #volume }

P11 `Vol`で、そのパッドだけの音量を調整します。

1. P11を押します
2. 下のダイヤルを回します
3. `Fn1`で他のサンプルと聞き比べます

音が割れる場合はVolumeを下げます。小さな音を無理に上げるとノイズも大きくなるため、必要なら録音からやり直します。

## Pitch { #pitch }

P12 `Pitch`でサンプルの音程と再生速度を変えます。

- 高くする：短く、明るい音になる
- 低くする：長く、重い音になる

1. P12を押します
2. 下のダイヤルを少しずつ回します
3. `Fn1`で確認します

## そのほかの編集項目

| パッド | 項目 | 役割 |
|---|---|---|
| P1 | `Chop` | サンプルを複数のSliceへ分割する |
| P2 | `Choke` | 同じグループの前の音を、新しい音で止める |
| P4 | `Delete` | サンプルを削除する |
| P5 | `Hold` | パッドを押している間だけ音を伸ばす |
| P6 | `Repeat` | サンプル全体またはGrid単位で繰り返す |
| P7 | `Reverse` | 逆再生する |
| P8 | `Synth` | サンプルを音階演奏用の音源にする |
| P9 | `Start` | 再生開始位置 |
| P10 | `End` | 再生終了位置 |
| P11 | `Vol` | パッド個別の音量 |
| P12 | `Pitch` | 音程と再生速度 |

Chop、Synth、細かなRepeat設定は発展機能です。まず基本3項目を調整し、PLAYへ戻って演奏してみましょう。
