# サンプルの応用操作

このページでは、サンプルの鳴り方を変える設定と、パッド間のMove、Copy、Mix、Deleteを説明します。基本のStart / End、Volume、Pitchを先に試しておくと理解しやすくなります。

[サンプル編集の基本](edit-sample.md){ .md-button }

## 鳴り方を変える

サンプル編集画面で設定します。

### Hold

P5 `Hold`は、パッドを押している間だけ音を鳴らす設定です。

- OFF：パッドを短く押してもサンプルの終わりまで鳴る
- ON：パッドを離した時点で音が止まる

長い声や楽器音を演奏するときに向いています。

### Repeat

P6 `Repeat`はサンプルを繰り返します。下のダイヤルで方式を選びます。

| 設定 | 動作 |
|---|---|
| `None` | 繰り返さない |
| `Whole Sample` | StartからEndまでを連続して繰り返す |
| `8 / 4 / 2 / 1 / 0.5` | LoopのGridに合わせてサンプルを繰り返す |

`Whole Sample`はビートへ同期しません。Grid指定はビートまたはRec Loopの速さに合わせて再トリガーします。

### Reverse

P7 `Reverse`をONにすると、Start / Endで指定した範囲を逆向きに再生します。声やシンバルを別の音のように変えたいときに使えます。

### Choke

P2 `Choke`をONにしたサンプル同士は、新しい音を鳴らすと前の音が止まります。開いたHiHatを閉じたHiHatで止める場合や、長いフレーズを重ねず切り替える場合に便利です。

## パッドをMoveする

1. `SAMPLER + SOUND`で移動元パッドを1回押し、音を確認します
2. 同じパッドをもう一度押したまま保持します
3. 移動先の空パッドを押します
4. 移動元パッドを離します

空パッドを選ぶとサンプルが移動します。Rec済みの演奏がある場合は、対応するパッド位置も移動先へ引き継がれます。

## Move後にCopyを残す

空パッドへMoveした直後、移動元パッドをまだ押している間に移動先パッドをもう一度短く押すと、元の位置にも同じサンプルをCopyできます。画面の`TAP TARGET AGAIN: COPY`案内が出ている間に操作します。

## 2つのサンプルをMixする

1. `SAMPLER + SOUND`で元になるパッドを選びます
2. 同じパッドをもう一度押したまま保持します
3. すでにサンプルが入っている別のパッドを押します
4. `MIXING`表示が消えるまで待ちます

2つのサンプルが1つの音として移動先パッドへまとめられます。やり直しに備え、重要なKitは先に保存してください。

## サンプルをDeleteする

方法は2つあります。

- サンプル編集画面でP4のゴミ箱を2回押す
- `SAMPLER + SOUND`で`Fn3`を押しながら対象パッドを選び、確認後に削除する

Deleteすると、そのサンプルのSynth、Repeat、Chokeなどの設定も消えます。保存済みの元WAV / MP3は削除されません。

!!! warning
    Move、Mix、Deleteはパッドの内容を変更します。大切な状態は[サンプルキットまたはProjectとして保存](../reference/save-and-restore.md)してから操作してください。
