# 用語集

## 基本の5用語

| 用語 | 意味 |
|---|---|
| サンプル（`Sample`） | パッドへ割り当てて鳴らす音 |
| ビート（`Beat`） | リズムの土台。Pattern、または繰り返し再生するWAV / MP3 |
| `Rec` | パッド演奏のタイミングを記録する機能 |
| `Loop` | Recで記録した演奏データと、その繰り返し再生 |
| `Music` | Music Playerで再生する曲全体のWAV / MP3 |

ビートとLoopは別のものです。ビートは演奏の土台、LoopはRecした演奏です。

## サンプルと音作り

| 用語 | 意味 |
|---|---|
| `Start / End` | サンプルを鳴らす範囲の始点と終点 |
| `Pitch` | サンプルの音程と再生速度 |
| `Hold` | パッドを押している間だけ音を鳴らす設定 |
| サンプルリピート（`Sample Repeat`） | 1つのサンプルを、サンプル全体またはGrid単位で繰り返す機能 |
| `Reverse` | サンプルの逆再生 |
| `Choke` | 新しい音で、同じグループの前の音を止める機能 |
| `Chop` | 長いサンプルを複数の短いサンプルへ分ける機能 |
| `Slice` | Chopによって作られた1つずつの短いサンプル |
| `Sustain Loop` | サンプルシンセで波形の一部分を循環させ、音を伸ばす機能 |
| `Release` | パッドを離したあと、音が消えるまでの長さ |
| パッドの基準音（`Pad Base Note`） | サンプルが元々持つ基準音程 |

Sustain Loopは音色を伸ばす内部の繰り返しで、Recによる演奏のLoopとは別です。

## ビートとタイミング

| 用語 | 意味 |
|---|---|
| パターンビート（`Pattern Beat`） | 短いドラム音と演奏パターンで作るビート |
| オーディオビート（`Audio Beat`） | WAV / MP3を繰り返して使うビート |
| `Tempo` | 演奏の速さ |
| `Grid` | Loop全体を等分したタイミングの目盛り |
| `Quantize` | パッド入力を近いGridへ合わせる機能 |
| `Note Grid` | Recで音を合わせる細かさ |
| `Swing` | 交互のタイミングをずらして跳ねたリズムにする機能 |
| ビートリピート（`Beat Repeat`） | ビートを1回、2回、4回繰り返してRec Loopの長さにする設定 |
| `FIT` | Chop素材を現在のビートまたはLoopの長さへ合わせる方式 |
| `KEEP` | Chop素材の元の速度と音程を保つ方式 |

## 演奏と保存

| 用語 | 意味 |
|---|---|
| `Mute` | 記録済みの演奏を一時的に鳴らさない機能。生演奏は鳴る |
| `Undo` | 現在パートの直前のRec操作を戻す機能 |
| `Mixer` | パートごとの一時音量とMuteを操作する画面 |
| `Mix 1〜4` | Mixerの音量とMute状態を保存して呼び出すSlot |
| `FX Target` | FXをかける対象 |
| `LIVE` | Music読込中の、ビート＋サンプラー＋Bass＋Melody＋Chord |
| `MUSIC` | Music Playerで再生する曲 |
| `Performance Recording` | FXを含む最終演奏を1本のWAVへ録音する機能 |
| サンプルキット（`Sample Kit`） | 12個のサンプルとパッド編集設定のセット |
| `Project` | サンプル、ビート、Rec、音楽設定、FX、Mixerを含む曲全体の保存単位 |
| `Resume` | 電源を切る前の状態を次回起動時に自動復元する仕組み |

## 音楽パート

| 用語 | 意味 |
|---|---|
| `Bass` | 曲の低音を演奏するパート |
| `Melody` | 単音の旋律を演奏するパート |
| `Chord` | 複数音の和音を演奏するパート |
| `Key` | 曲の中心となる音 |
| `Scale` | パッドへ並べる音の組み合わせ |
| `Octave` | 同じ音名の高さの範囲 |
| `Pitch Bend` | 演奏中の音程を滑らかに上下する操作 |
| `Modifier` | Chordへ7th、sus4、9thなどの変化を加えるパッド |

## 接続と管理

| 用語 | 意味 |
|---|---|
| `File Editor` | PCやスマートフォンからSDファイルを管理し、サンプルをパッドへAssignする画面 |
| `Assign` | 音や外部入力へ、パッドまたは操作の役割を割り当てること |
| `Input Source` | 使用する外部コントローラーの種類 |
| `Learn` | 外部のキーやボタンを押して割り当てを覚えさせる操作 |
