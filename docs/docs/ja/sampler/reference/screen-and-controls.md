## 画面の見方

画面下側の表示と、本体のボタンは同じ並びです。

![画面下側のモード、パッド、Fnの表示と本体ボタンの対応](../assets/images/screen-button-mapping.png){ .screen-button-mapping loading=lazy }

### 1. 現在のパート

画面左上の`SAMPLER`は、現在選んでいるパートです。本機には次の5パートがあります。

- `BEAT`
- `SAMPLER`
- `BASS`
- `MELODY`
- `CHORD`

最初のチュートリアルでは`SAMPLER`を使います。

### 2. 演奏表示エリア

画面上側の大きな領域です。PLAY、REC、編集内容に応じて、波形やLoop上の演奏位置などを表示します。

### 3. 4つのモード

画面中央の`SOUND / PLAY / REC / FX`は、同じパートで何をするかを切り替えます。

| モード | 役割 |
|---|---|
| `SOUND` | 音源を選ぶ、録音する、編集する |
| `PLAY` | サンプルを自由に演奏する |
| `REC` | 演奏を記録してLoopにする |
| `FX` | 再生音へエフェクトをかける |

本体画面の下にある4つの黒いボタンが、同じ並びのモードボタンです。選択中のモードは明るく表示されます。

### 4. ボタン機能表示エリア

画面の`SOUND / PLAY / REC / FX`から下は、本体のボタンに対応した格子状の表示です。モードボタン、パッド、Fn1〜3で使える機能を示します。

写真では、8つの初期サンプルが色付きのタイルとして表示されています。右側の縦列は、再生やミュートなどを行うFn1〜3の役割を示します。

Fnの役割はモードや画面によって変わります。その時に使える操作を画面のアイコンで確認してください。

## 物理ボタンの並び

大きな白いボタンは5列x3段です。

- 左4列：12個の演奏用パッド
- 右端列：上から`Fn1`、`Fn2`、`Fn3`

初期状態では、上2段の8つのサンプラーパッドにサンプルが入り、下段の4つは空です。

## 右側のダイヤル

- 上のダイヤルを回す：全体の音量
- 上のダイヤルを押す：すべての音とLoop再生を停止
- 下のダイヤルを回す：通常画面ではパートを選ぶ。メニューや編集画面では項目や値を動かす

!!! tip
    操作中に分からなくなったり音が止まらなくなったりした場合は、まず上のダイヤルを押してください。
