# サンプルから楽器を作る

サンプルシンセを使うと、1つのサンプルを音程に合わせて鳴らし、Bass、Melody、Chordの音源として演奏できます。声の「あー」、単音の楽器、持続するシンセ音などが向いています。

打楽器、複数の音程が同時に鳴る素材、音程が大きく動く素材は、最初の練習には向きません。

## 仕組みを知る

サンプルシンセでは、サンプルの最初の部分を鳴らしたあと、安定した波形の一部を`Sustain Loop`として繰り返します。パッドを離すか音の終わりへ進むと、`Release`で自然に音を閉じます。

ここでいうSustain Loopは、Recで作る演奏のLoopとは別の機能です。

## 1. サンプルを用意して整える

1. 単音のサンプルをサンプラーパッドへ追加します
2. `SAMPLER`の`SOUND`モードで、そのパッドを2回短く押してEditへ入ります
3. Start / End、Volume、Pitchを必要に応じて調整します
4. P8 `Synth`を押します

[サンプルを編集する](../tutorials/edit-sample.md){ .md-button }

## 2. Sustainを試す

サンプルシンセ画面では、最初にP9 `Sustain`を選び、下のダイヤルでモードを変えます。

| 設定 | 動作 |
|---|---|
| `OFF` | Sustain Loopを使わず、サンプルを通常再生する |
| `AUTO` | 安定して繰り返せる区間を本体が探す |
| `ON` | P10 `In`とP11 `Out`で指定した区間を使う |

初心者はまず`AUTO`を選びます。`NO SUSTAIN`と表示された場合は、そのサンプルには安定して繰り返せる区間が見つかっていません。別のサンプルを試すか、`ON`で手動調整します。

`Fn1`はPreviewです。サンプルシンセ画面では、`Fn1`を押している間Sustainが続き、離すとReleaseへ移ります。

## 3. Attack、Tune、In / Out、Releaseを調整する

- P4 `Atk`：発音時の音量の立ち上がりを選ぶ
- P5 `Tune`：元サンプル固有の音程ズレを1 cent単位で合わせる
- P10 `In`：Sustain Loopの開始位置。下のダイヤルで動かす
- P11 `Out`：Sustain Loopの終了位置。下のダイヤルで動かす
- P12 `Rel`：パッドを離したあとの音の消え方を選ぶ

不自然な周期音やクリックが聞こえる場合は、InまたはOutを少しずつ動かします。音を素早く止めたい場合は短いRelease、余韻を残したい場合は長いReleaseを選びます。Tuneは音色固有の補正なので、曲全体のKeyやTuneを変えても保持されます。

!!! note
    SustainとReverseは同時に使えません。Sustainを有効にするとReverseはOFFになります。`Whole Sample`のRepeatとも同時には使えません。

## 4. Bass、Melody、Chordへ割り当てる

サンプルシンセ画面の上段で、使いたいパートを選びます。

| パッド | 割り当て先 |
|---|---|
| P1 `Mel` | Melody |
| P2 `Chord` | Chord |
| P3 `Bass` | Bass |

誤操作を防ぐため、同じパッドをもう一度押すと割り当てが確定します。割り当て済みのパッドを同じ手順で押すと解除できます。

## 5. 音階で演奏する

1. `Fn2 OK`で編集を確定します
2. 下のダイヤルを回し、割り当てたBass、Melody、またはChordへ移動します
3. PLAYモードで12個のパッドを鳴らします

本体はサンプルの基準音程`Base Note`を自動推定します。音程が合わない場合は、各パートの`Sound Source`で`Pad Sample`を選び、同じパートメニューに表示される`Base Note`から元サンプルの音名を手動で選びます。

## 向いているサンプル

- 1音だけを長めに鳴らした声や楽器音
- 音程が安定している音
- ノイズや余韻が少なく、Start / Endを決めやすい音

Chopで作ったSliceはリズム位置を保つため、サンプルシンセへは割り当てられません。
