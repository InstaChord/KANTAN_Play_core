# KANTAN Sampler マニュアル

サンプラーとは、さまざまな「音」をボタンに割り当て、効果音を鳴らしたり、音楽を作ったりできる電子楽器です。

KANTAN Samplerには、音を鳴らす基本的なサンプラー機能に加え、曲作り、DJのような演奏、音楽再生など、音楽を楽しむための機能が手のひらサイズの本体に詰まっています。

操作はかんたんです。フルカラーの大きな画面に、そのとき使える機能が分かりやすく表示されるので、初心者の方でもすぐに音あそびを始められます。

<div class="manual-start" markdown>

[はじめての5分を始める](quickstart.md){ .md-button .md-button--primary }

演奏を楽しみながら、KANTAN Samplerの基本操作を覚えられます。

</div>

## やりたいことから選ぶ { #choose-by-purpose }

「はじめての5分」を終えたら、興味のある使い方から進んでください。すべてを順番に読む必要はありません。

<div class="manual-route-grid" markdown>

<div class="manual-route-card" markdown>

### 効果音を好きなときに鳴らす

好きなWAV・MP3ファイルをボタンに割り当て、必要なタイミングで鳴らします。配信や舞台、イベントなどの「ポン出し」にも使えます。

[ポン出しの使い方](guides/soundboard.md){ .md-button }

</div>

<div class="manual-route-card" markdown>

### 音楽のループを作る

ビートに合わせてボタンを演奏し、その演奏を記録します。ベース、メロディー、コードも重ねられます。

[音楽のループを作る](guides/loop-making.md){ .md-button }

</div>

<div class="manual-route-card" markdown>

### 曲を切り分けて遊ぶ

曲や長い音声から使いたい部分を切り出し、複数のボタンに分けて自由に演奏します。

[曲を切り分ける](guides/chop.md){ .md-button }

</div>

<div class="manual-route-card" markdown>

### 曲を流しながら演奏する

曲全体を再生しながら、効果音や合いの手を好きなタイミングで加えます。

[曲を流しながら演奏する](guides/music-player.md){ .md-button }

</div>

<div class="manual-route-card" markdown>

### DJのように音を変化させる

演奏やループにエフェクトをかけ、リアルタイムで音の動きや雰囲気を変えます。

[DJのように演奏する](guides/dj-performance.md){ .md-button }

</div>

<div class="manual-route-card" markdown>

### 録音した音から楽器を作る

録音した音や読み込んだ音に音程をつけ、ベース、メロディー、コードとして演奏します。

[音から楽器を作る](guides/sample-synth.md){ .md-button }

</div>

</div>
